solidjs-components

Formbird custom elements on the in-memory host. Everything below is set up the way fieldtec-web does it: element properties, ChangedDocumentService, SearchClientService.

Projects/SDMS/

Description

Switching projects on the Team Intrays Board re-renders every status lozenge twice: once with the previous project's colours and again after the status query returns. Reproduces on slow connections.

Labels

Details

Lists (<solid-table>)

The tables of formbird/templates/solid-issue-list.template.json: sorting, paging and search run as Elasticsearch queries against the in-memory host. Resize the window to see columns drop by the table's width.

Photos and pins (<solid-photo-capture>, <solid-image-pins>)

An incident: take, upload or drop photos (each uploads to the in-memory host straight away; large ones are scaled down first), click one for the lightbox (← → to move, Esc to close). Below, where the person was hurt: click the body to add a pin, drag pins to move them, or use Add pin with the keyboard.

Read-only photos and pins, file references

mode: "view", readOnly: true, and fieldtec-web's own file reference documents (fileDetails): an image shows as a photo, a PDF as a file with a download link.

New issue

Empty document: no key yet, empty status, unassigned. Required fields are validated like fieldtec-web does on save.
